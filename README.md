# ShadowsocksX-NG Linux

A Linux/Ubuntu desktop client inspired by ShadowsocksX-NG.

## Goal

Provide a lightweight GNOME-friendly desktop experience for Shadowsocks with:

- System tray controls
- Off / PAC / Global proxy modes
- Shadowsocks server profiles
- SIP003 plugin support, including simple-obfs
- Integration with `ss-local`
- GNOME system proxy integration
- Auto-start support

## Status

Early development.
